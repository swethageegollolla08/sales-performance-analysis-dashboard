# Sales Performance Analysis Dashboard

## Project Overview

This project analyzes sales data to understand revenue and business performance across different regions, product categories, customer segments, and time periods.

The dashboard was developed using **Excel and Microsoft Power BI** to transform raw sales data into interactive business insights.

## Business Objective

The objective of this project was to:

* Analyze sales trends over time
* Compare performance across regions
* Identify high-performing product categories and sub-categories
* Understand customer segment contribution
* Analyze the relationship between discount and profit
* Identify areas that could support better business decisions

## Dataset

* **Records:** 9,994+
* **Time Period:** 2014–2017
* **Data Source:** Sample Superstore dataset
* **Tools:** Excel, Power BI, Power Query

## Data Preparation

The raw Excel data was imported into Power BI and prepared using **Power Query**.

The preparation process included:

* Checking data types
* Cleaning the dataset
* Transforming data where required
* Preparing the data for visualization and analysis

## Dashboard

The Power BI dashboard includes:

* KPI metrics
* Sales Trend Analysis
* Region-wise Performance
* Category and Sub-category Analysis
* Customer Segment Analysis
* Discount vs. Profit Analysis
* Interactive slicers for filtering the analysis

## Excel Analysis

An Excel companion report was created using PivotTables and PivotCharts.

A Pareto analysis showed that **6 of 17 sub-categories contributed approximately 80% of total revenue**, highlighting the concentration of revenue among key sub-categories.

## Key Insights

* Sales performance varied across regions and customer segments.
* Some product sub-categories contributed significantly more revenue than others.
* Higher discount levels were associated with lower profitability in parts of the dataset.
* A relatively small number of sub-categories contributed a large share of total revenue.

## Outcome

The project demonstrates how **Excel, Power Query, and Power BI** can be used to clean, analyze, and visualize business data and translate the results into actionable insights.
